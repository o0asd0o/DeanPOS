- [007: The shared UI package — Tailwind 4's shared theme file, two vendored primitives, and a contrast test with no library behind it](007-shared-ui-dependency-set.md) — **React 19.2.8 named here, because no manifest declared one**; the focus indicator is a `@layer base` `:focus-visible` rule in the same shared file, adopting SC 2.4.13's AAA figures because AA's "visible" is not testable; grants a narrow exemption from code standard 2 for generated files under `packages/ui/src/components/`; `apps/landing` deliberately outside `packages/ui` until area 11, which reuses the same `theme.css` through `@tailwindcss/postcss`; **the Tailwind major is the one part that is not affordably reversible** and carries a named re-check trigger, Stakes: high

no `@testing-library/jest-dom`, no `user-event`, no devtools, no `@tanstack/react-router-with-query`, no second Vitest; `environment: "happy-dom"` set per-app because `environmentMatchGlobs` was removed in Vitest 4, and RTL auto-cleanup does **not** fire without global `afterEach`, so the helper registers it, Stakes: high
- [009: The terminal shell's chrome — what renders when there is no tenant, no cashier, no network, and no data yet](009-terminal-shell-chrome-states.md) — answers screen-triage question 3 for issue 06, which issue 07 consumes unchanged; one principle applied six times: **render what is true, render nothing where nothing is true, and never let a state be a shape nobody drew**; the mock's three top-bar slots become one — the start slot renders the literal `DeanPOS` and the `OFFLINE · 3 queued` and `Ana (cashier) · Lock` slots render **no element at all**, not a dimmed placeholder and not an empty reserved box, with `justify-between` carrying the mock's order so areas 2 and 5 add a child and move nothing; focus is record 007's rule **confirmed, not re-decided**, plus three constraints it does not give (DOM-order focus, no `overflow-hidden` clipping the 2px-at-2px-offset ring, no per-component restyling); hover exists only on `packages/ui`'s `Button` and **nothing in `apps/pos` may be reachable only by hover** (it is a touch device); `Try again` is **never disabled** — TanStack Query dedupes in-flight fetches, and a disabled button leaves the tab order at the worst moment; loading is **one line of `<p role="status">Loading…</p>`, never a skeleton or spinner** (the README lists them under "Not drawn, on purpose" and a skeleton is a shape nobody drew), with the header and frame painted on first paint; **there is no empty state — a ping that returns no row is an error, not "nothing here yet"**, since the row is a migration invariant (standing rule: an empty list is an empty state, a missing singleton is an error); the error is a `role="alert"` block with two plain sentences and a retry, in `--color-foreground` on `--color-background` because `--color-destructive` on `--color-background` is **not in record 007's asserted pairing table**, carrying no status code, no URL and no server text; the two layouts are a **CSS `md:` media query, not JavaScript and not a container query**, with regions that have no content rendering no element; plus `lang`, `<title>`, a viewport meta with **no scale lock**, one `<header>`/one `<main id="main-content">`, no skip link in `apps/pos` (nothing repeats) and one in `apps/backoffice` (the sidebar does), and no motion anywhere in the chrome; the four sentences of copy are replaceable without a new record, the roles/region/retry/no-technical-detail rules are not; least-confident value is the 768px `md` boundary, which is a Tailwind default and carries a re-check trigger, Stakes: medium
