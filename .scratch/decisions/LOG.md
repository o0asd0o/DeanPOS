- [005: The Prisma commands become root scripts, and the root `.env` reaches them](005-prisma-command-scope-and-env.md) — resolves the ADR-0004 / ADR-0008 / issue-03 contradiction: `prisma` stays in `packages/backend` only, and root `codegen`/`migrate`/`migrate:status` scripts scope into it with `vp exec -F backend`; the three `ORC2_*_CMD` values become `vp run -w <script>`; the migrate scripts source the root `.env` because Prisma never searches parent directories; a root `prepare` hook makes `vp install` alone reach a green gate.
