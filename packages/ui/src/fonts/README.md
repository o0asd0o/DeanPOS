# Manrope

`Manrope-Variable.woff2` is a variable font (weight axis 200–800, used here at
400–700) converted from the upstream TrueType source published in the
[google/fonts](https://github.com/google/fonts/tree/main/ofl/manrope)
repository (`ofl/manrope/Manrope[wght].ttf`), converted to `woff2` with
`fonttools`. Licensed under the SIL Open Font License 1.1 — see `OFL.txt` in
this folder, copied from the same upstream directory.

Self-hosted per ADR-0003 (offline-first): no CDN, no `@import` from Google.
